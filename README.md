# 声迹 SoundTrace

**本地会议录音库 —— 导入、离线转写、点字跳音频、全文检索、AI 会议纪要。**

会议录音不该躺在手机里吃存储，复盘也不该靠拖进度条反复听。声迹把录音集中到电脑统一管理：本地离线转写（内容不出本机）、转写稿与音频时间对齐（点字即跳）、全文检索秒级定位、一键生成 AI 会议纪要。

## 核心特性（V1）

- **工作台**：处理队列优先的首页 —— 正在转写 / 排队中 / 最近完成一目了然，可单条取消；统计卡给出录音总数、待处理、本周完成、累计时长
- **导入归档**：拖拽 / 选文件夹批量导入，按内容哈希去重，按年月自动归档，支持 m4a / mp3 / wav / amr / 3gp 等手机常见格式（不兼容格式自动转码 m4a 副本）
- **批量转写**：录音库勾选多条一次排队，串行执行、进度实时可见
- **离线转写**：FunASR 系 Paraformer-large 模型（ONNX，本地推理），中文优先优化，字符级时间戳；silero-VAD 分段 + CT-Transformer 自动标点
- **转写不抢机器**：转写进程以低于前台的优先级运行，机器空闲时满速、你一动手就让路；默认只占「逻辑核心 - 2」，边转写边开会办公不卡（设置页可切「全部核心」或自定义线程数）
- **处理流水线**：每条录音的归档 / 波形 / 转写 / 说话人 / AI 纪要五个阶段可见，各带产物与状态，可单独重跑
- **点字跳音频**：转写稿与波形播放器时间对齐，点击任意文字即跳转对应音频位置；跟随播放自动滚动
- **转写稿编辑**：就地改错字、删段、与下一段合并、从时间中点拆段；手工修改会被标记，重新转写前给出明确提示
- **说话人分离**：自动分离（pyannote 分段 + CAM++ 声纹，锁人数聚类 + 碎片吸收），人数按参会人预填、可改；转写前预设人数则转写完自动接分离（队列串行、工作台可见）；手工标注与合并不被自动分离覆盖
- **说话人标注**：按段标注说话人并命名，支持按人筛选与着色；把拆错的簇一键并回一个人
- **全文检索**：录音标题 / 标签 / 笔记 / 参会人 / 转写全文子串搜索（符合中文检索习惯），片段命中直达时间点
- **AI 复盘**：转写稿一键提炼核心结论（含被否决方案）、难点盲点诊断（含糊表达 / 反复解释的术语，附费曼式消歧）、知识标签自动回写；所有时间戳可点击跳回原声（OpenAI 兼容 API，GLM / DeepSeek 等均可配置）
- **导出**：Markdown 会议纪要 / SRT 字幕 / 纯文本
- **深浅双主题**：跟随系统 / 深色 / 浅色，切换即时生效并记忆选择

## 技术栈

| 层 | 选型 |
|---|---|
| 壳 | Tauri 2（Rust，Windows 优先） |
| 界面 | React 19 + TypeScript + Vite + Tailwind CSS 4，深浅双主题，中文界面 |
| 数据 | SQLite（rusqlite bundled），库文件按年月目录归档 |
| 转写 | sherpa-onnx（Rust crate，静态链接）+ Paraformer-large int8 + silero-VAD + CT-Transformer 标点 |
| 分离 | sherpa-onnx + pyannote-segmentation + 3D-Speaker CAM++，跑在独立子进程；锁人数聚类（自动阈值实测不可用，见开发记录） |
| 复盘 | OpenAI 兼容 Chat Completions API（可配置 Base URL / Key / Model） |
| 媒体 | ffmpeg（转码、峰值预计算），波形前端自绘（Canvas + 预计算峰值，不解码大文件） |

数据目录：`~/SoundTrace/`（录音库、数据库、模型、缓存，可在设置中修改）。

主题实现：色阶（`ink` / `mist` / `st-*`）是语义槽位而非字面颜色，由 `src/styles.css` 的
`@theme inline` + `:root[data-theme]` 变量重映射驱动，浅色下明暗关系整体反转；
组件里只写槽位类名，不写具体色值。

## 开发

```bash
# 前置：Rust(MSVC) + Node 22 + pnpm + WebView2；ffmpeg 在 PATH（转写/峰值需要）
pnpm install
pnpm tauri dev      # 开发
pnpm tauri build    # 打包

# 图标：编辑 brand/icon.svg 后重新生成
cd tools/icon-gen && cargo run          # 渲染 1024 母图
cd ../.. && pnpm tauri icon brand/icon-1024.png
```

## 首次使用

1. 启动后进入「设置」→ 下载离线模型（转写约 310MB + 说话人分离约 34MB）
2. 回到「工作台」，点「导入文件夹」把手机录音整个目录导进来（也可以直接拖到窗口里）
3. 在「录音库」勾选若干条 → 「批量转写」；任务会出现在工作台的「处理队列」里推进
4. 打开任意录音 → 左栏「处理流水线」看各阶段产物；转写稿里点任意文字即跳到对应音频位置
5. 需要错字修正或说话人标注时，直接在转写稿里改（双击段落 / 悬停段落右侧按钮）；想自动分说话人，在流水线「说话人分离」选人数点一下，拆错了用转写稿工具栏的「合并」一键并回
6. 需要会议纪要时，在设置里填好 LLM（Base URL / API Key / 模型），详情页「AI 纪要」标签页点「生成纪要」
