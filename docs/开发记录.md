# 声迹 SoundTrace · 开发记录

## 已完成里程碑

### M0 立项 + 应用骨架 ✅

- 品牌：声迹 SoundTrace，identifier `com.soundtrace.desktop`
- 图标：`brand/icon.svg`（深空蓝底 + 青色声波 + 翡翠追迹线）→ `tools/icon-gen`（resvg）渲染 1024 母图 → `pnpm tauri icon` 全套
- SQLite schema v1（settings / recordings / segments / tags / recording_tags / bookmarks / jobs），WAL 模式
- 数据目录 `~/SoundTrace/{library,models,cache}`，可通过 `bootstrap.json` 重定向
- 应用壳：侧栏导航（录音库 / 设置）、深色主题（Tailwind 4 + 自定义 ink/mist/teal 色板）

### M1 导入与库管理 ✅

- 拖拽 / 选文件 / 选文件夹（递归扫描）导入；扩展名白名单
- xxh3_128 流式哈希去重（重复导入提示"库中已有：标题"）
- ffprobe 提取时长与录制时间（回退文件 mtime），按 `library/YYYY-MM/{标题}_{hash12}.ext` 归档
- amr / 3gp / wma 等浏览器不可播格式导入时自动转码 m4a（ffmpeg AAC 192k）
- 标题 / 参会人 / 标签 / 笔记编辑；删除（可选同时删文件）

### M2 波形播放器 ✅

- ffmpeg 流式解码 → 100ms 分辨率峰值（3 小时 ≈ 108,000 点），存 BLOB 复用
- Canvas 自绘波形：已播青色 / 未播暗蓝、点击与拖动跳转、平方根幅度缩放
- 播放 / 暂停（空格）、后退 10s、前进 30s、0.5~3x 倍速、书签（B 键，可命名、点击跳转、删除）
- asset 协议运行时放行库目录，`convertFileSrc` 播放

**播放放行验证**（`cargo test --test asset_scope`）：复现 Tauri `push_pattern` / `canonicalize_parent` / `Scope::is_allowed` 的路径规范化过程，确认 ① 归档音频被放行、② 递归覆盖嵌套子目录、③ 库目录外文件与兄弟目录被拒绝、④ Windows `\\?\` verbatim 前缀模式同样匹配。注意 `glob::Pattern::escape` 会转义 `*`，通配符必须转义路径后再单独拼接（Tauri 的 `escaped_pattern_with` 即如此）。


### M3 离线转写 ✅

- **引擎**：sherpa-onnx 1.13.8（静态链接 Rust crate）
  - ASR：Paraformer-large int8（`sherpa-onnx-paraformer-zh-2023-09-14`，**字符级时间戳**）
  - VAD：silero-vad（threshold 0.5 / 最小静音 0.5s / 最长语音 15s）
  - 标点：CT-Transformer zh-en-vocab272727 int8
- 流水线：ffmpeg 转 16k 单声道 → VAD 分段 → 逐段 Paraformer 识别 → 字符时间戳映射到全局时间轴 → 标点恢复
- 模型管理器（设置页）：分项状态、下载进度事件、断点续传（`.part` 临时文件 + 已存在跳过）
- 后台工作线程：轮询 pending 任务、进度事件、可取消、重启后 running → pending 自动续跑
- 转写稿面板：虚拟滚动、**点字跳转音频**（字符级）、点击分段跳转、跟随播放自动滚动、稿内搜索（Enter 跳转 + 高亮）

**验证**：`cargo test e2e_chinese_transcription` —— Windows TTS 生成中文会议语音 → 全流程转写，识别文本与原文逐字一致（含标点与数字），时间戳单调递增。约 23s 完成 30 秒音频（首次含模型加载）。

### M4 检索 / AI 复盘 / 导出 ✅

- 全局搜索：标题 / 标签 / 笔记 / 参会人 + 转写全文子串匹配（LIKE，中文友好），片段命中带上下文摘要，点击直达时间点
- AI 复盘：OpenAI 兼容 Chat Completions（GLM / DeepSeek / OpenAI 可配）
  - ≤3 万字一次成稿；超长转写自动分段小结 → 合并（支持 3 小时会议）
  - 输出章节：会议概要 / 关键信息与决议 / 行动项（表格）/ 待澄清问题
  - 结果 Markdown 渲染、可重新生成、设置页带连通性测试
- 导出：Markdown（含纪要）/ SRT 字幕 / 纯文本

**验证**：`cargo test --test pipeline` —— 导入 → 去重 → 元数据 → 转写 → 分段入库 → 搜索命中 → 三种格式导出 → 级联删除，全链路通过。

## 开发命令

```bash
pnpm install
pnpm tauri dev                     # 开发（Rust 首次编译约 1 分钟）
pnpm tauri build                   # 打包

cd src-tauri
cargo test                         # 全部测试（含端到端转写，首次会下载模型）
cargo test --test pipeline         # 仅全链路集成测试
cargo test e2e_chinese_transcription -- --nocapture   # 仅转写引擎

# 图标更新
cd tools/icon-gen && cargo run && cd ../.. && pnpm tauri icon brand/icon-1024.png
```

## 已知边界

- 转写仅 CPU（RTF ≈ 0.12~0.22，8 核；3 小时录音约 22~40 分钟）
- 首次使用需在设置页下载模型（约 310MB，存于 `~/SoundTrace/models`）
- ffmpeg / ffprobe 需在 PATH（转码、峰值、解码均依赖）
- AI 复盘需自备 LLM API Key（录音不外传，仅转写文本发送）
